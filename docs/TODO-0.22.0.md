# Moose 0.22.0 计划执行记录与 TODO

更新：2026-10-03。0.22.0 已联合发布；下面区分实现、已验证和仍未完成的工作。详细功能对照及测量见 [验收记录](releases/0.22.0-validation.md)；本轮逐项断言、原始报告与截图见 [证据索引](releases/0.22.0-evidence.md)。

## 本轮执行计划（2026-10-03）

范围：补齐可自动执行的验收与证据；人工系统验收由用户选择另约。当前工作区包含发布后的提交和未提交修改，所有新结果标记实际 HEAD、工作区差异与构建摘要，不追认发行包通过，不覆盖公开版本。

1. **P0 证据核对**：查找原实施 worktree，恢复失败长运行报告及原始日志；归档来源、SHA-256 和缺失项，建立证据索引。
2. **P0 长运行诊断**：记录操作阶段、页面／进程关闭与崩溃、预期退出、后台日志、进程身份和清理结果；先短测覆盖重连及桌面重开，再启动固定两小时负载。
3. **P1 自动回归与功能对照**：检查当前构建，运行完整单元与桌面／Web E2E；将 13 类功能对应到具体测试名称、断言和未覆盖分支。
4. **P1 文档资源与动效**：归档带构建身份的关键截图；执行焦点、反向过渡、窄屏与减少动态效果检查。自动测量和隐藏截图不替代前台人工观察。
5. **P0 结果审阅**：对两小时固定阶段样本审阅 RSS／堆、进程／连接变化，核对草稿、原 PTY 及测试子进程退出；失败则保留原报告并定位，不仅凭退出码勾选通过。
6. **P1 补充边界流程**：新增合并冲突重开恢复后的完成／中止界面检查，以及桌面／Web 连续快速切换；保留首次测试设置失败和修正后的复测结果。
7. **P2 另约人工验收**：真实休眠／唤醒、桌面及浏览器系统通知、VoiceOver 和前台动效观察；准备可复现步骤，未执行保持待办。

执行结果：P0／P1 自动工作已完成；192 项单元、原有 73 项 E2E 及补充定向回归通过，两小时负载与资源趋势复核通过。继续执行时新增的 4 项 E2E 均通过，当前共 77 项用例；新增后仅定向复测，未重跑全套 77 项。结果仅对应本轮源码构建。P2 按用户选择另约；历史关闭根因因缺少当时事件继续作为证据限制。
