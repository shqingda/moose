# 复健题单

答题稿在 [answers](../README.md)。这里不是另一套讲义，是同一批题的练口稿。

每题都按这个顺序说：

| 小节 | 你要说出来的 |
| --- | --- |
| **这题在考什么** | 什么场景会碰到，面试官想听你分清什么 |
| **一句话回答** | 先把结论说完 |
| **展开说明** | 按这个顺序把理由补上；对比用表 |
| **示例** | 只拿来讲，不是项目源码 |
| **Moose 里的做法** | 0.23.3 里真实有的行为 |
| **容易答错的地方** | 写了「没有」的，不要说成已经做了 |
