# 使用指南

适用于 0.23.1。浏览器怎么连见 [Web 使用说明](web.md)，各代理支持什么见[能力表](providers/native-capabilities.md)。

文中的**底座**指本机安装的代理 CLI，目前是 Codex、Grok Build、Pi 和 OpenCode。Moose 不自带这些程序，也不代为登录。

先记住四件事，后面的步骤都绕着它们：

| 这件事 | 实际意味着 |
| --- | --- |
| 代理要自己安装、自己登录 | Moose 只检测连接，不代为安装 CLI，也不保存它的登录凭据 |
| 关掉窗口不等于停掉任务 | 安装版普通退出后，共享后台和终端还在。要停，得按 [Web 说明](web.md#桌面安装版在浏览器中打开同一工作区) 停止后台 |
| 编辑一条消息不会把代码改回去 | 重新发送只替换这一轮对话，工作区里的文件保持现状 |
| 桌面和独立 Web 的数据不自动合并 | 桌面在 `~/Library/Application Support/Moose`，命令行安装的 Web 在 `~/.moose/web` |

## 安装与连接

从 [GitHub Releases](https://github.com/shqingda/moose/releases/latest) 下载 arm64 DMG，将 Moose.app 放入 Applications。安装包采用 ad-hoc 签名并验证完整性，尚未进行 Apple Developer ID 签名及公证；首次下载若被 Gatekeeper 拦截，可在“系统设置 → 隐私与安全性”中允许打开。

没有可用代理时，欢迎页和输入区都有连接入口，点进去就是对应服务商的设置。

设置页把连接分成四种：未安装或未找到、已禁用、连接失败、可用。每种都给出官方指南，也可以复制接入命令。安装和登录要在终端里做，Moose 不会代装 CLI。

装好并登录之后，打开 **设置 → 代理连接** 刷新检测。自动发现读取登录 shell 的 PATH，并补上常见安装目录。shell 的别名和函数不当作可执行文件。

还是找不到时，填写可执行文件的绝对路径，点击输入框外面就会保存。保存中、已保存、保存失败会分别提示。保存成功只说明路径写进去了，不代表已经连上；保存失败时，框里的字会留着。

| 代理 | 连接说明 |
| --- | --- |
| Codex | 使用已安装的 CLI，先执行 `codex login` |
| Grok Build | 先在官方 CLI 完成登录 |
| Pi | 在 `pi` 中用 `/login` 连接模型服务，详见 [Pi 接入](providers/pi.md) |
| OpenCode v2 | 要求 v2，在 CLI 执行 `opencode auth login`；安装命令与验证范围见[能力表](providers/native-capabilities.md#opencode-v2) |

模型、推理档位和图片能力按 CLI 实际返回的信息展示。上次选过的底座、模型、推理强度、权限和任务模式会在下次打开或新建会话时直接恢复；如果那一项已经不可用，会换成仍有效的默认值，不用重新手选。已有会话固定代理，换代理需要新建会话。

## 更新桌面版

1. 打开 **Moose → 检查更新…**，有新版时点击“前往下载”；也可直接访问[正式发布页](https://github.com/shqingda/moose/releases/latest)。
2. 下载 Apple Silicon DMG，普通退出桌面客户端后，将新版 Moose.app 替换到 Applications，再打开应用。应用不会自动下载或替换自身。
3. 普通退出会保留共享后台和任务。若新版提示后台版本不同，先等现有任务结束，退出桌面后按[共享后台操作](web.md#桌面安装版在浏览器中打开同一工作区)停止旧后台，再打开新版。只关闭窗口或普通 ⌘Q 不能切换正在运行的后台版本。

替换应用不迁移或删除工作区数据。命令行安装的独立 Web 使用另一套安装目录，更新方法见[Web 更新](web.md#更新独立-web-版)。

## 外观与图标

在 **设置 → 通用 → 主题** 中选择跟随系统、浅色或深色。字号会一起放大正文、导航和辅助文字。系统的“减少动态效果”“减少透明度”和“提高对比度”仍然生效，换主题不会把它们关掉。

macOS 应用和 Dock 使用白底拟物图标；会话区欢迎画面使用去掉圆角底托的透明拟物 logo，保留金色鹿角、象牙白鹿头与黑色眼睛。侧边栏继续使用随界面文字颜色变化的原有驼鹿剪影。

Web 标签页图标跟随操作系统主题：浅色系统使用深色剪影，深色系统使用浅色剪影；它独立于应用内主题选择。更新后浏览器仍显示旧图标时，先刷新页面，必要时关闭并重新打开该标签页。资源维护见[图标与品牌资源](development.md#图标与品牌资源)。

## 工作区入口

打开项目之后，界面分成下面这几块。具体怎么操作，在后面各节。

侧栏顶部固定“新建会话”和“搜索会话”，中间按项目分组，底部固定归档与设置。项目行和会话行的操作可以用鼠标悬停、键盘聚焦或触屏打开。完成和空闲的会话不显示状态图标。

顶部左侧显示项目、会话与实际工作目录；独立 worktree 会显示其目录。右侧依次为文件、审阅、终端与更多。原生会话、独立工作目录、Finder 与外部编辑器入口集中在更多菜单。设置分为通用、代理连接、扩展，原有配置、通知和快捷键保留。

新会话把输入区放在画布中央，发送后位于对话底部。输入区直接显示任务模式、权限和模型分组；模型菜单中选择代理、模型及其实际支持的推理档位。

文件与审阅使用同一辅助区。分隔条支持拖动与左右方向键，宽度偏好共用；关闭后焦点返回打开入口。窄屏 Web 覆盖显示辅助面板，关闭可回到原对话。面板切换保留草稿和文件阅读位置，终端换位置继续复用原进程。

## 项目、会话与输入

打开项目后即可输入。点击“新建会话”先进入空白输入页，首次发送才保存会话。项目行可折叠会话列表，不切换当前对话。

- `@` 搜索项目文件和目录；`/` 选择当前代理支持的任务模式或技能，也可直接使用输入区的任务模式菜单。删除引用文本也会移除对应上下文。
- 附件可选择、拖放或粘贴；每次最多 10 个、单个 20 MB。图片支持取决于底座和模型，视频不支持。
- 运行中普通发送会进入队列，可编辑或取消。Codex、Grok、经验证的 Pi 1.x 的“立即发送”使用原生插话，追加到当前回合；不改变当前模型、权限或任务模式。Pi 的回执里可以没有这一轮的原生编号；停止任务时会先清掉还没送出去的插话。底座拒绝时保留输入；超时或断线后结果可能未知，先核对状态，不要马上再发一次。
- 停止任务或后台重启后，队列保持暂停，需要主动恢复。同一实际目录中的代理任务串行，不同目录或 worktree 可以并行。
- 只能编辑最近一条用户消息，附件保持不变；重新发送会替换该轮对话，**不会回滚代码文件**。
- 会话先归档，再从归档列表恢复或删除。普通归档可在 10 秒内撤销；悬停或键盘聚焦提示时暂停计时。有排队消息时先确认暂停，恢复或撤销归档不会自动继续执行队列。删除项目只移除 Moose 中的记录，不删除代码目录或 CLI 历史；仍有受管 worktree 时需先清理。

输入区里的审批档位决定代理能执行到什么程度，管不到你自己打开的终端。四个底座都有请求批准、帮我批准和完全访问，也都可以用计划模式和目标模式。没有保存过选择时，权限默认是帮我批准。完全访问只有你明确选中才会用。每家底座怎么实现这些模式，见[能力表](providers/native-capabilities.md)。

输入框模型名前的用量指示器可悬浮查看，也支持键盘打开。只显示底座提供的上下文或套餐数据，不估算缺失额度。

## 状态、搜索和结果查看

侧栏用图标显示运行、等待你的操作、排队、失败和中断，完成与空闲不显示图标；悬停提示与读屏名称说明状态。点击含待处理事项的会话可定位问题、审批或待批准计划；处理完成后回到实时消息。输入区显示后台提供的排队原因，可跳转到占用同目录的任务、终端或命令。连接恢复不会抹掉尚未处理的操作错误；操作结果未知时应先核对状态，不直接重复发送。

搜索支持全部项目、当前项目或当前会话，匹配项目名、会话标题及已保存消息的标题和正文，包含归档会话，不搜索草稿或隐藏配置。每页 50 条，可以继续加载。上下键选择，Enter 打开，Escape 关闭；Ctrl／⌘+Home／End 跳到当前已加载结果的首尾。Tab 直接到“清空”和“加载更多”，不会逐条停在结果上。消息结果会定位并高亮原文；你正在翻历史时，新回复不会把阅读位置拉走，要点“回到最新消息”才恢复跟着最新内容走。

### 文件面板

顶部“文件”按钮打开右侧面板，与“审阅改动”共用侧栏位置。消息中的本地文件链接和改动列表的预览，也会在这里打开。面板只读，不修改源文件。

- **找文件**：展开目录或按文件名搜索，支持多个标签。Tab 进入文件树，上下键移动，左右键展开／收起／返回上级，Home／End 到首尾，Enter 打开；Tab／Shift+Tab 离开，再进入时回到上次位置。目录使用当前会话实际位置（含 worktree），隐藏 `.git` 和符号链接；单目录超过 2,000 项会提示截断。
- **读代码**：支持语法高亮、行号、⌘/Ctrl F 查找并按匹配行跳转、换行切换和复制。
- **读 Markdown**：默认显示渲染预览，可切换源码；相对链接和图片以当前文件所在目录解析。
- **调整与刷新**：拖动左边缘调整宽度；右上角展开／还原面板，聊天草稿保留。刷新按钮重读目录与当前文件。

图片附件可点开放大；工作区图片在右侧文件面板中预览。文本／代码最多显示前 1 MiB，图片最多 20 MiB；PDF 等文件提供另存副本。文件读取限制在会话实际目录（包含对应 worktree）或 Moose 附件目录内，越界链接不能读取。远程图片显示为外部链接，不自动加载。代码块有独立复制和自动换行按钮；连续输出及工作区刷新保留操作状态。

### 通知

在 **设置 → 通用 → 通知** 中可分别开启问题／审批、任务完成／失败提醒，默认关闭。当前正在查看的会话不提醒，多窗口共享后台只分配一次通知；点击可回到对应会话。通知只包含项目、会话标题和状态。桌面进程或 Web 页面需保持打开；关闭窗口但桌面进程仍运行时可提醒，退出桌面或关闭所有 Web 页面后不保证提醒。系统／浏览器可能阻止通知，可在对应设置中允许；重连不补发旧通知。

## 原生计划、历史与子代理

下面几项不是每家代理都有。某家现在开不开，以[能力表](providers/native-capabilities.md)为准。这里只写已经接上之后，界面上怎么用。

Codex 的 `/plan` 使用原生规划模式。生成计划后可修改正文、保存版本，再点击“批准并执行”；执行恢复会话原先的权限档位。计划完成不会自动运行排队消息，批准前应先处理已有队列。同一版本不能重复批准。

顶部 **⋯ → 原生会话** 可浏览、预览和导入支持的 CLI 历史。Codex 还支持显式分叉和手动压缩。导入是历史快照，不会持续同步外部 CLI 的新消息；分叉只分开对话，不隔离代码目录。

Codex、Grok 根据任务自行决定是否使用原生子代理，Moose 没有委派开关。活动中可查看底座返回的状态与结果；Codex 另有独立历史面板，控制操作受原生活动连接和能力限制。不能把“加载子会话”当成“恢复已关闭的子任务”。

## 隔离目录与 Git 审阅

需要并行修改同一项目时，从 **⋯ → 独立工作目录** 创建 worktree 和新会话。新目录从指定 Git ref 创建，不复制原目录的未提交内容、依赖或聊天历史。会话中的执行、文件引用、终端和 diff 都使用该目录。

在右侧“审阅改动”中查看已暂存、未暂存和未跟踪文件，包括代理开始前就存在的改动。可逐文件暂存、填写提交说明并核对预览；预览后内容变化需要重新确认。当前不支持按代码块暂存。

“拉取请求”使用已登录的 `gh`，针对同一 GitHub origin 上已推送的分支创建草稿 PR。源分支不能与目标分支相同；Moose 不自动推送，也不支持跨 fork PR。Codex 的“原生代码审查”运行在独立只读会话，可能消耗模型额度。

Worktree 面板提供合并预览、冲突处理、继续和中止。清理前会检查任务、未提交文件、忽略文件和未合并提交；清理不会自动删除分支。

## 配置与扩展

从 **设置 → 扩展** 进入，不用先打开项目。这里改的是所选底座的**用户级**配置，会影响以后的会话；项目自己的配置仍可能盖过它。页面只显示已经接上的操作。其他底座的 OAuth、Hooks，以及 Grok 的默认模型，仍在 CLI 里改。各家具体开到哪一步，以[能力表](providers/native-capabilities.md)为准。

| 操作 | 会发生什么 |
| --- | --- |
| 启用、禁用、保存默认模型 | 直接生效 |
| 安装或卸载插件，新增或编辑 MCP | 先给出确认预览。写入前会核对读到的配置版本，避免盖掉你在外面刚改过的文件 |
| 有代理任务正在跑，或正在编辑一条消息 | 先等它结束。配置写入和任务共用一把锁，避免一边改 CLI 配置、一边用旧配置执行 |
| 新增 MCP | 默认禁用，核对后再单独启用。凭据填环境变量名，表单里不填密钥本身 |
| 编辑已有配置 | 没改到的字段保留。用户级修改会作用到其他项目 |
| 页面重新得到焦点，或空闲满 30 秒 | 重读配置，磁盘上已经删掉的条目会从列表消失。正在编辑时不自动刷新 |
| 连接失败 | 不删除磁盘上的配置 |
| 删除已有 MCP 服务器 | 界面没有这个按钮。要停用，用启用开关；需要删文件时到 CLI 里做 |

## Pi 与 OpenCode 的历史限制

Codex、Grok 的导入见上一节，入口同样是 **⋯ → 原生会话**。再导入同一来源会打开已经有的 Moose 会话，续聊保留原生标识。浏览不向模型发任务，导入也不删除、不改写源历史文件。Pi 和 OpenCode 还有各自的限制：

- Pi 只读解析 JSONL 版本 2 和 3，按最后保存的那条分支处理压缩摘要和保留范围。文件损坏、路径越界、体积过大或不支持的格式会整份拒绝，不会导入一半。默认读取 `~/.pi/agent/sessions`，并尊重 CLI 的目录环境变量。导入后仍要在输入区选择“完全访问”。
- OpenCode 要求 v2，通过它自己的会话列表和回放来加载历史。会话按实际目录隔开，macOS 上同一路径的不同写法也会对上。

## 终端、命令与定时任务

顶部终端按钮打开面板，可在弹窗、底部、右侧之间切换；没有终端标签时自动开启一个，已有标签时复用现有 Shell。切换位置保留进程和输出。

| 页签 | 用途 |
| --- | --- |
| 终端 | 交互式 zsh，支持 vim、Ctrl+C、粘贴和尺寸同步；可同时打开多个标签 |
| 命令 | 手动运行一次 Shell 命令，查看输出、发送标准输入、结束输入或停止 |
| 定时任务 | 创建单次、固定间隔、每天或每周指定日的定时任务，可选时区并预览下三次时间 |

终端标签上的 **×／结束终端** 会先确认，默认聚焦取消；确认后结束对应 Shell 及其中的程序并移除标签。关闭最后一个标签，或最后一个 Shell 自行退出时，整个终端面板自动收起，弹窗、底部和右侧行为一致；面板关闭按钮只隐藏面板。已关闭终端没有历史回顾入口，重启也不恢复原进程。命令页里的命令点击运行才执行，**不是每次开始对话时自动执行**。

手动命令与终端可以并行；它们仍占用目录，代理执行、定时任务及需要独占目录的写操作需等待。终端内容不会作为聊天输入发给模型。

定时任务可执行 Shell 命令或向已有会话发送代理消息；后者可能消耗模型额度。编辑前先暂停，预览并保存后仍保持暂停。暂停只影响未来触发，不停止已领取的任务；失败或结果未知会暂停后续执行。错过多个周期最多合并补跑一次，不保证崩溃期间每次都必达。没有月度规则、任意 cron 或系统唤醒功能。

## 退出、重连与数据

安装版自动启动本机共享后台。菜单 **Moose → 检查更新…** 可检查正式版本并前往下载。

| 操作 | 后台任务与终端 |
| --- | --- |
| 关闭桌面窗口或浏览器页面 | 继续运行 |
| 安装版普通退出（⌘Q） | 继续运行 |
| 停止共享后台服务 | 停止 |
| 默认独立开发模式退出 | 随应用停止 |
| 电脑休眠、断网或重启 | 不保证继续执行；重启不恢复活进程 |

升级若提示后台版本不同，等活动任务结束后停止旧后台，再重新打开 Moose；应用不会自动停止旧后台。后台不随电脑开机自动启动。多窗口共用终端时只有一个窗口控制输入与尺寸，其他窗口可查看或手动接管，详见 [Web 使用说明](web.md#多窗口终端控制)。

正式数据位于 `~/Library/Application Support/Moose`，开发版位于 `~/Library/Application Support/Moose Dev`。历史、草稿、队列和附件保存在本机；后台重启会核对中断状态，不自动重发未确认操作。代理仍需连接其模型服务，本机存储不等于离线推理。

### 终端字符与复制

新终端会为缺失或非 UTF-8 字符环境设置 UTF-8，避免提示符符号乱码。更新前已打开的 shell 可执行 `export LC_ALL=en_US.UTF-8` 立即修正后续输出，不必停止其中的任务。该设置仅影响当前 shell 及之后启动的子进程。

选中文字后用 ⌘C（或 Ctrl+Shift+C）复制；Ctrl+C 仍用于中断命令。桌面使用系统剪贴板；Web 优先使用浏览器剪贴板，受限时尝试原生复制，若浏览器仍拒绝会保留错误提示。
