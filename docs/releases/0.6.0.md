# Moose 0.6.0

## 新增

- 接入 Pi（pi.dev）：模型与推理档位探测、流式回复、思考内容、工具记录、图片及文件附件、停止与原生会话恢复。
- 服务商设置和模型选择器增加 Pi；支持 Pi 全局和项目 skills。

## 代码整理

- 统一代理注册、配置字段和能力声明，减少重复分支。
- 复用 RPC 传输和附件文本处理，移除设置保存后的重复探测。
- 使用 Oxc 格式化及检查代码，补充主要函数注释和 Pi 接入文档。

- 文档集中到 docs，统一使用、架构、开发、验证及面试入口，并区分历史记录。

## 验证与说明

- 31 项单元测试、14 项 Electron 端到端测试通过。
- arm64 安装包签名严格校验通过；实际启动确认版本 0.6.0、sandbox 开启及 SQLite 可用。
- Pi 0.85.1 真实 CLI 握手通过；当前测试环境未配置 Pi 模型，真实模型生成尚未验收。
- Pi 没有内置审批沙箱，需明确选择完全访问；不提供原生 Plan/Goal 模式或套餐额度查询。
- macOS Apple Silicon 安装包采用 ad-hoc 签名，并严格校验签名。未进行 Apple Developer ID 签名及公证，首次下载仍可能被 Gatekeeper 拦截；可在系统设置的“隐私与安全性”中允许打开。有效签名不等于已公证，下载隔离标记仍由 macOS 管理。

安装 Pi 后在终端完成登录，再到 Moose 设置中刷新检测；找不到 CLI 时填写其绝对路径。
