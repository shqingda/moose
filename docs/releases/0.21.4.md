# Moose 0.21.4

2026-09-30，macOS 桌面与独立 Web 联合发布，版本统一来自 `package.json`，标签为 `v0.21.4`。[GitHub Release](https://github.com/shqingda/moose/releases/tag/v0.21.4)。

## 标题栏与侧栏过渡

- 修复左侧边栏按钮与项目文件夹、右侧工具栏图标之间的半像素高度偏差。标题栏分隔线改为不占布局空间的绘制方式，图标共用同一水平中心线。
- 修复折叠时文件夹和项目名称先跳向右侧、再回拉的瞬间位移。侧栏宽度、标题栏左侧留白及 Web 侧栏按钮共用一个无回弹的弹簧进度，展开和折叠同步平滑移动。
- 动画中途再次点击可从当前位置和速度连续反向；保留减少动态效果时的立即切换，窄屏 Web 的覆盖式侧栏不移动标题。
- 保留当前会话、输入草稿与后台活动任务。

## 验证与安装

桌面与 Web 回归用例按帧检查标题不超出起止位置、展开与折叠单向移动，以及中途反向。联合发布流程 `pnpm release:prepare`、`pnpm release:publish` 覆盖格式、Lint、类型／构建、全部单元与 E2E、桌面包严格签名和运行、独立 Web 干净安装及更新保留任务；部署后从正式公网入口重新安装验证，通过后才公开 GitHub Release。底座协议未重新进行真实模型验收。

| 文件 | 用途 |
| --- | --- |
| `Moose-0.21.4-arm64.dmg` | macOS Apple Silicon 桌面安装包 |
| `Moose-0.21.4-web-darwin-arm64.tar.gz` | 独立 Web 安装包 |
| `Moose-0.21.4-SHA256SUMS.txt` | 两端安装包 SHA-256 |
| `install.sh` | [独立 Web 公网安装入口](https://moose.shqingda.workers.dev/install.sh) |

桌面下载新版并替换应用，见[桌面更新](../usage.md#更新桌面版)；独立 Web 执行 `moose update`，活动任务结束后重启后台，见[Web 更新](../web.md#更新独立-web-版)。
