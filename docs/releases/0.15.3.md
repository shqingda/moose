# Moose 0.15.3

修正模型选择按钮的留白与顶部控件对齐，精简模型选择窗口。

- 模型按钮恢复左右内边距，文字与箭头统一居中。
- 顶部侧边栏开关、项目名称和右侧工具按钮统一垂直中心；项目名称使用普通图标与文本，不再显示为按钮。
- 模型选择窗口缩小为更紧凑的固定尺寸，选项改为单行，移除重复的底座名称；保留搜索和内部滚动。

提供 macOS Apple Silicon DMG 与 SHA-256 文件，沿用 ad-hoc 签名，未做 Apple 公证。

验证：150 项单元测试、46 项完整桌面／Web E2E 通过；格式、lint、类型与构建检查通过。签名和 DMG 完整性校验通过，实际启动确认版本、沙箱、SQLite、Shell、终端停靠与日历编辑正常。未调用真实模型。
