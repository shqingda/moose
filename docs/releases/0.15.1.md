# Moose 0.15.1

本版精简首屏加载和发行包内容，整理重复测试与未使用代码。

- 对话渲染、设置页面和 Web 入口按需加载；首屏主 JS 从 1,272.67 kB 降至约 895 kB。设置首次打开后保留内部状态和关闭动画。
- macOS arm64 发行包排除其他平台预编译文件、依赖源码和生产 source map，保留当前架构的 SQLite、PTY 与辅助程序。安装后的应用从约 323 MiB 降至 292 MiB。
- 删除未使用的 Field 组件辅助函数、Separator 文件和旧手工 UI 验收脚本；启用 TypeScript 未使用变量与参数检查。
- 合并两项重复 E2E，保留有价值的行为断言，减少脆弱的像素间距检查。单元测试保留协议时序、错误恢复和安全边界。
- 测试文档改为当前验证方法，历史结果统一查阅发布记录；面试指南补充 Electron 性能优化的测量、取舍与边界。

新增 `pnpm perf:measure`，测量已打包应用。三次空工作区温缓存启动的中位数从 568 ms 到 503 ms；样本较少，不代表普遍的冷启动提升。内存变化很小，尚不足以证明显著改善。完整口径见[项目追问资料](../interview/project-interview-reference.md#electron-启动慢包体积大内存高你怎么优化)。

提供 macOS Apple Silicon DMG 与 SHA-256 文件，沿用 ad-hoc 签名，未做 Apple 公证。

验证：150 项单元测试、46 项完整桌面／Web E2E 通过；设置状态保留调整后补跑 3 项相关回归通过。格式、lint、类型、构建和签名严格校验通过。实际启动 0.15.1，确认沙箱、SQLite、Shell、终端三种停靠布局与日历编辑正常；DMG 完整性校验通过。未调用真实模型。
