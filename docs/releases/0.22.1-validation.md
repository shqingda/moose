# 0.22.1 维护版发布验收

日期：2026-10-03（Asia/Shanghai）。用户已确认按 0.22.1 维护版联合发布；真实休眠／唤醒、系统通知、VoiceOver 和前台动效另约，历史异常关闭根因继续保留待查。

## 范围与来源

- 纳入 0.22.0 发布后的设置导航文字／快捷键标题微调、未使用组件和模块导出清理、长运行诊断修正、测试及文档补强。
- 版本以 `package.json` 为唯一来源；macOS Apple Silicon DMG、独立 Web、Git tag 与 GitHub Release 使用同一个 0.22.1。
- 此前 192 项单元、原有 73 项 E2E、新增 4 项定向回归与两小时固定负载的结果保持原构建身份，见 [0.22.0 证据索引](0.22.0-evidence.md)。本次完整重新执行发布准备，不把先前源码结果写成本版安装包结果。
- 测试使用临时数据目录、协议夹具与本地 Shell，不发送真实模型任务，不改用户工作区或重启用户活动后台。

## 联合发布步骤

1. 提交版本、说明、代码、测试与证据，确保工作区干净。
2. `pnpm release:prepare`：格式、Lint、单元、类型／构建、官网类型／构建、全部 77 项 E2E、桌面签名和安装包检查、独立 Web 干净安装／更新保任务／失败保旧版验证。
3. `pnpm release:publish`：核对准备提交和两端校验值，推送代码／标签，上传草稿安装包，部署 Web，完成公网安装验证后公开 Release。

状态：发布准备中，尚未记录本版通过结果。完整控制台输出保存在本机 `.moose-test/releases/0.22.1/`；成功或失败都保留原始记录，完成后补充脱敏归档及安装包校验值。
