# Moose 0.23.0

一次聚焦加载、资源占用与交互一致性的更新。保留现有项目、会话、终端和代理能力，数据库格式保持兼容。

- 首屏按实际使用加载功能，欢迎图使用适合屏幕显示的透明资源，减少首次下载与图片解码开销。
- Web 静态资源支持流式读取、gzip、条件请求和内容指纹缓存；HTML 保持重新验证，更新后继续获取当前入口。
- 流式消息更新避免重复排序，过期或重复消息保留原状态，减少长会话中的分配和无效渲染。
- 统一菜单、弹窗与提示的可反向过渡；补齐按钮尺寸语义、即时按压反馈和辅助偏好支持。
- 搜索自动聚焦，键盘选中项有明确高亮，支持一键清空并继续输入；复制消息补充读屏反馈，复用时间格式器并清理提示计时器。

macOS Apple Silicon DMG 与独立 Web 使用同一版本联合发布。自动流程验证桌面签名、完整功能回归、Web 干净安装与更新保任务，并在公网安装通过后公开 Release。测量条件、实际结果和保留限制见[本版验收](https://github.com/shqingda/moose/blob/main/docs/releases/0.23.0-validation.md)。
