# Moose 0.10.0

## Git 操作与原生代码审查

- 右侧改动面板支持逐文件暂存／取消暂存、完整暂存范围预览和提交；HEAD 或暂存区变化后要求重新预览，失败保留提交说明。
- 支持 GitHub 草稿 PR 创建及状态查询，明确核对 origin、目标分支和已推送的 HEAD；已有 OPEN PR 返回原链接，不自动推送。
- Codex 0.155+ 可原生审查未提交改动、相对分支或指定提交。使用独立只读线程，结果、文件行号、状态和停止操作与执行会话分开。
- 提交／PR 请求保存意图与回执；审查中退出或断连会保留可解释的状态，不自动重试消耗模型额度。
- 修复从 Git 子目录打开项目时的暂存路径解析，并确保 diff.relative 不会隐藏提交预览范围。

## 支持范围

PR 首批支持同一 github.com origin 的已推送分支，需要本机安装并登录 gh。暂不支持跨 fork、其他托管平台或自动 push。普通提交保留 Git hooks 和签名；合并冲突继续使用 Worktree 的专门流程。

本轮自动化使用临时真实 Git 仓库、协议 fixture 和本地 GitHub CLI fixture，没有调用真实模型或创建真实远端 PR。真实模型审查仍受底座版本、登录与额度影响。[第四阶段验收说明](../providers/phase-four-testing.md)提供零模型 token 的复测命令。

提供 macOS Apple Silicon（arm64）DMG 与 SHA-256 校验文件；沿用 ad-hoc 签名，尚未 Apple 公证。
