# Moose 0.20.0

桌面版与 Web 独立安装版同步发布，统一版本号 0.20.0。

## Web 修复与适配

- 设置页移除桌面标题栏留白，滚动区域贴合窗口边缘；窄窗口导航、侧栏、审阅面板和右侧终端停靠分别适配，避免主界面被挤出窗口。
- 同时支持 localhost 与 127.0.0.1；两种访问链接连接同一个后台。
- 跟随系统的主题、减少动态效果、透明度和对比度变化即时同步。
- Web 设置页展示浏览器快捷键：Alt+Shift 加对应字母，终端保留 Ctrl+反引号；保留浏览器的新窗口、打开文件和地址栏快捷键。支持聚焦输入框。
- 登录失效时在当前页面重新认证，保留未发送草稿并恢复事件订阅；写操作不自动重试。
- 切换到后台或离开页面时刷新待保存草稿，短草稿请求允许在页面退出后完成。
- 扩展认证在网页提供可直接点击的授权链接，避免异步打开页面被浏览器拦截；桌面仍自动打开授权页面。
- 独立启动器检查正在运行的后台版本；更新后提示用户在任务结束时停止旧后台再重启。

## 安装与更新

macOS Apple Silicon Web 安装：

```sh
curl -fsSL https://moose.shqingda.workers.dev/install.sh | sh
```

新终端输入 `moose` 自动打开浏览器。`moose start` 仅启动服务，`moose status` 查看状态，`moose stop` 停止后台及其任务。

安装包自带 Node.js、SQLite 和 PTY，无需预装 Node.js、pnpm 或编译器。代理 CLI 仍需单独安装和登录。升级时重新执行安装命令；已有任务结束后执行 `moose stop`，再执行 `moose`。

桌面 DMG 与 Web 安装包均针对 macOS Apple Silicon。桌面使用 ad-hoc 签名，未进行 Apple 公证。Web 版不具备桌面原生菜单和 Finder／编辑器打开能力，相关入口在 Web 中隐藏；服务执行和项目目录都属于运行 Moose 的机器。

## 发布验证

统一发布流程验证格式、Lint、类型、单元测试、桌面／Web E2E，随后检查桌面签名、沙箱、SQLite、Shell、PTY 和调度，以及无系统 Node 的 Web 安装、校验失败、重装、浏览器启动、认证和终端执行。正式地址安装验收通过后才公开桌面 Release。两端安装包附 SHA-256 校验值。
