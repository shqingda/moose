# Moose 0.13.0

本版整理工作区操作，终端可在弹窗、底部与右侧之间切换。

- 终端填满顶部操作栏之外的空间，移除重复标题与说明；切换位置保留当前 Shell、输出和对话草稿，并记住用户选择。
- 底部和右侧面板参与工作区布局，不遮挡对话；右侧终端打开时再打开 Git 审阅，终端移到底部。关闭面板仅隐藏界面，停止按钮才结束进程。
- 顶部保留终端、工具、改动审阅三个入口。历史、独立工作目录、扩展与会话管理集中到分组文字菜单。
- 补齐菜单键盘导航、弹窗关闭后的焦点返回、长标题截断和窄窗口布局。
- 历史与 worktree 状态区减少嵌套边框，Git 暂存操作与文件名并排。

40 项完整 Electron 回归通过；最终工具栏收紧后，终端三种布局再次定向验证。构建、类型、lint、格式检查通过，测试未调用真实模型。

提供 macOS Apple Silicon DMG 和 SHA-256 校验文件。沿用 ad-hoc 签名，尚未 Apple 公证；数据库保持 schema 5。

发行包验收通过：DMG 完整性与 deep／strict 签名检查；实际启动 0.13.0 验证沙箱、SQLite、Shell 输入输出、终端三种位置切换及日历任务编辑。位置切换后仍为同一个运行中的终端。
