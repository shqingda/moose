# Moose 0.5.4

面向 Apple Silicon Mac 的本地 Coding Agent 客户端。本次发布汇总近期交互优化与修复，仅发布 0.5.4 安装包。

## 会话与侧边栏

- 点击项目行仅折叠或展开会话列表，右侧保留当前会话。
- 统一侧边栏字号与图标对齐，保持紧凑行高；执行中的会话以旋转指示器表示状态。
- 移除“回到这条消息”；保留消息复制和最新一条用户消息的就地编辑。
- 编辑后在原会话重新生成，替换该轮对话并保留原附件，不再新增重复会话；不会回滚工作区文件。
- AI 回复跨工具调用合并复制，悬浮消息时在操作按钮右侧显示时间。
- 无可用思考摘要时隐藏占位提示，返回实际摘要时正常展示。

## 模型、额度与设置

- 合并代理与模型选择器，支持按代理浏览、搜索模型，完整展示长模型名称；推理强度独立选择。
- 服务商列表更紧凑，移除整行悬浮底色，支持启用或停用已检测到的 CLI。
- 支持查看上下文用量与套餐额度，快捷键为 `⌘ U`；按代理实际返回的窗口展示剩余额度和重置时间。
- 接入 Grok Build 额度查询；Codex 通用额度优先展示，套餐名称统一展示一次。
- 缓存额度查询并合并并发请求，减少重复加载。
- 优化设置页、侧栏和审阅面板交互，以及文件、技能引用的输入体验。

## 下载与使用

下载 `Moose-0.5.4-arm64.dmg`，打开后将 Moose 拖入 Applications。

- 仅提供 macOS Apple Silicon（arm64）安装包。
- 需自行安装并登录 Codex CLI 或 Grok Build；Moose 复用本机 CLI 登录状态。
- 当前安装包未签名、未公证，首次打开可能需要在 macOS“系统设置 → 隐私与安全性”中允许打开。
- Grok 的能力取决于 CLI 支持情况；本次已验证真实额度读取，额度耗尽后的生成与续聊尚未完成真实验收。

## 验证

类型检查、25 项单元测试、13 项 Electron 端到端测试通过；arm64 打包及打包后应用启动、沙箱配置和 SQLite 初始化检查通过。
