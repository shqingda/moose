# Moose 0.12.0

本版补齐交互式终端、日历调度和 Codex MCP 连接管理，并整理扩展与后台任务界面。

- 交互式终端支持真实 Shell、按键输入、窗口尺寸同步和 vim 等全屏程序；关闭面板后继续运行，重新打开可回看输出。运行时退出会回收所拥有的终端进程，重启不重放输入。
- 定时任务新增每天／每周指定日、执行时间和时区；保存前展示下三次执行时间。夏令时缺失时刻跳过、重复时刻仅执行一次，暂停恢复从下个时间点继续。
- Codex 用户 MCP 连接支持编辑、移除和引用环境变量的 HTTP 请求头；保留密钥与未编辑的高级字段，版本校验防止覆盖新配置。
- 扩展按 MCP、插件、代理、诊断分区；后台面板按终端、命令记录、定时任务分区。新建表单按需展开，修改确认展示可读字段。
- 新增完整项目面试指南，涵盖项目架构、原生能力适配、任务生命周期和实现取舍。

134 项单测、38 项 Electron 桌面回归通过，类型、lint、格式检查通过。测试使用隔离数据和测试底座，不调用真实模型。

提供 macOS Apple Silicon DMG 与 SHA-256 校验文件。沿用 ad-hoc 签名，尚未 Apple 公证。定时任务仍要求 Moose 进程运行；应用退出后执行、系统唤醒与任意 cron 未接入。数据库保持 schema 5。

发行包验收通过：DMG 映像校验、deep／strict 签名检查；实际启动包内 0.12.0 应用确认 renderer sandbox、SQLite、Shell 输入输出、PTY 和日历任务编辑均可用。
