# Moose 0.23.2

只做启动和资源优化，功能和界面不变。计划见[性能重构计划](../perf-refactor-plan.md)。

- 后台更早启动：主进程不再等窗口第一次请求，启动时直接拉起后台；等待连接文件的轮询从 200ms 改为 10ms。
- 底座探测提前到后台启动后立即进行，窗口第一次刷新直接复用这一轮，不阻塞窗口显示。
- 每家底座上一次成功的探测结果存进本地数据库，下次启动先显示，再用新结果覆盖。改了某家的配置、CLI 被删除或升级时，旧结果不会显示。
- 四个底座适配器改为用到时再加载；桌面后台和 Web 后台共用一份服务代码，桌面包不再打两份后台。
- 渲染进程和后台开启 V8 代码缓存，第二次启动少编译一次。
- 修复读取 CLI 版本时偶尔读不完输出的问题，OpenCode 不再在启动时偶尔误报版本过低。
- 测量脚本按进程分别统计内存，并记录启动各阶段的时间。

Linux 打包构建上，窗口就绪中位数约 570ms 降到约 350ms，有缓存时底座列表出现从约 790ms 降到约 345ms，app.asar 减小约 5.7%。macOS 数据以本版验收为准。

macOS Apple Silicon DMG 与独立 Web 使用同一版本联合发布；验证记录见[本版验收](https://github.com/shqingda/moose/blob/main/docs/releases/0.23.2-validation.md)。
