# Moose 0.18.0

统一为更克制的 Apple 风格界面，保持现有功能与操作流程。

- 日间以白色内容区和近白侧栏为主，夜间减少面板之间的明度差；蓝色用于主要操作与焦点反馈。
- 统一输入框、消息、设置分组和浮层的圆角与层级，减少不必要的外框。
- 收窄终端会话标签，保留整个标签的统一悬浮背景。
- 优化设置页窄窗口布局、弹窗长标题与滚动边界，补齐减少透明度设置和关闭按钮本地化。
- 未新增依赖，未修改代理协议或会话数据结构。

发行包为 macOS Apple Silicon DMG，使用 ad-hoc 签名，未进行 Apple 公证。

验证：159 项单元测试、47 项桌面／Web 回归全部通过；格式、lint、类型、构建和 337 个本地文档链接检查通过。安装包后台启动、沙箱、SQLite、Shell、PTY、调度、应用签名及 DMG 校验通过。测试不调用真实模型。
