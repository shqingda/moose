# Moose 0.15.0

本版新增 OpenCode v2 接入、Grok 原生插话，以及可与桌面共享后台的本机浏览器实验入口。

- OpenCode v2 通过 ACP 接入：模型发现、文本与思考输出、工具状态、权限审批、取消和会话恢复；图片支持遵循底座握手能力。暂不提供其原生 Plan／Goal、独立历史与扩展管理入口。
- Grok Build 运行中可“立即发送”，调用原生 `_x.ai/interject`；普通发送仍由 Moose 排队。明确拒绝保留草稿，断线或超时显示投递结果未知，不自动重发。
- 本机 Web 复用桌面界面和业务服务，支持令牌登录、项目选择、附件上传、审批和终端。macOS 本机直接调用系统目录选择器；远程入口使用服务端目录浏览。
- 桌面可显式连接同一后台，共享项目、会话、审批和终端。共享启动命令自动连接已有后台或启动新实例，提供状态查询和停止入口；关闭客户端不停止后台任务。
- 浏览器侧边栏重新适配：品牌、搜索、新建会话及折叠按钮统一对齐，折叠动画不再裁切静止文字。
- 项目经历整合进面试指南，整理文档导航、架构与能力边界。

Web 与共享后台目前从源码启动，见 [Web 使用说明](../web.md)。DMG 默认后台和历史保持原有方式，不自动迁移。尚未提供开机后台服务、流式终端续传和多客户端终端控制权；移动端适配、云端部署暂缓。临时 HTTPS 隧道不是托管部署。

提供 macOS Apple Silicon DMG 和 SHA-256 校验文件，沿用 ad-hoc 签名，未做 Apple 公证。

验证：150 项单元测试和完整 48 项桌面／Web 回归通过；格式、lint、类型与构建检查通过。测试使用隔离数据库、真实 Shell 和测试 CLI，不消耗模型 token。OpenCode v2.0.10 已完成真实握手与模型发现；Grok 1.0.34 已确认识别插话扩展，真实模型采纳插话尚未实测。

发行包验收通过：deep／strict 签名校验、DMG 完整性与 SHA-256 校验；实际启动 0.15.0，确认沙箱开启、SQLite 可用、Shell 输入输出正常、同一终端在弹窗／底部／右侧切换后保留，以及暂停的日历任务可编辑。
