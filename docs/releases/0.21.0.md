# Moose 0.21.0

桌面版与独立 Web 安装版使用同一版本 0.21.0 联合发布。

## 操作反馈与恢复

- 侧栏区分运行、待处理、排队、失败和中断；待处理会话直达问题、审批或计划。后台提供排队原因，并可查看占用目录的任务、终端或命令。
- 结束终端前确认，默认聚焦取消；面板隐藏继续保活，退出提示区分共享后台和独立开发模式。
- 普通归档可撤销，含排队消息时先确认暂停；恢复不会自动重放队列。
- 连接入口提供代理状态、官方指南与接入命令；路径保存与连接反馈分开。断线状态不覆盖操作错误，未知写入结果不自动重试。
- 补充中英文提示、可访问名称、代码块复制、附件预览失败和重试。

## 搜索、提醒与文件

- 搜索项目名、会话标题和已保存消息，支持范围、50 条分页、键盘选择及旧消息定位。草稿和隐藏配置不进入搜索。
- 问题／审批及完成／失败通知可分别开启，默认关闭。同一后台的多个客户端只提醒一次，当前查看会话不提醒，重连不补发旧事件；通知不包含正文。
- 图片可放大，文本／代码可只读预览与复制；附件、本地文件链接及改动列表可另存副本。远程图片不会自动加载。
- 文件访问限制在会话实际目录或附件目录，拒绝越界和文件替换；保存副本不能覆盖正在读取的源文件。

## 验证与边界

发布流程执行格式、Lint、类型、单元测试、桌面与 Web 回归，并验收 arm64 桌面包、Web 干净安装及公网安装入口。测试使用隔离数据与本地 CLI 夹具，不调用真实模型、不停止正式任务。

10,000 条约 1 KiB 消息的本地搜索基准 P95 约 33 ms（macOS arm64 / Node 26.10.0）；另有搜索期间真实 PTY 响应用例。通知接口模拟验收覆盖权限拒绝及多窗口去重，不等同于系统通知权限的人工验收。

通知依赖客户端保持打开及系统授权；无退出后常驻通知组件。文本预览限前 1 MiB、图片预览限 20 MiB，PDF 等通过另存查看。安装目标仍为 macOS Apple Silicon，桌面使用 ad-hoc 签名，未进行 Apple 公证。
