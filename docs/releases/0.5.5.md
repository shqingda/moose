# Moose 0.5.5

## 更新

- 重做驼鹿侧脸图标：深松绿底、暖白剪影与哑金掌状鹿角；同步应用内标识及 macOS 图标。
- 修正 macOS 打包签名：由跳过签名改为 electron-builder 原生 ad-hoc 签名，重新封装应用及嵌套组件的签名。
- 增加打包后签名检查：`codesign --verify --deep --strict` 不通过时中止打包，避免再次发布签名无效的应用。

## 安装与首次打开

下载 `Moose-0.5.5-arm64.dmg`，将 Moose 拖入 Applications，替换旧版。

此版本适用于 Apple Silicon Mac，使用 ad-hoc 签名，尚未使用 Developer ID 签名或 Apple 公证。有效签名解决文件完整性问题，不代表 Apple 已验证开发者身份。

浏览器下载时 macOS 会添加 `com.apple.quarantine` 隔离标记，发布者无法通过预先清除标记来阻止下载后重新添加。首次被拦截时，可前往“系统设置 → 隐私与安全性 → 仍要打开”。

如果确认文件来自本 Release，且仍无法打开，可以在安装到 Applications 后，仅移除 Moose 的隔离标记：

```sh
xattr -dr com.apple.quarantine /Applications/Moose.app
```

此操作不关闭系统 Gatekeeper，也不改动会话数据。请勿对来源不明的应用使用。正式消除“未验证开发者/未经公证”的拦截，需要 Developer ID Application 证书及 Apple 公证；当前没有可用的分发证书，不能声称已完成公证。

参考：[Apple 关于安全打开应用的说明](https://support.apple.com/102445)。

## 验证

构建及类型检查通过；应用签名严格校验通过，DMG 挂载后再次校验应用签名通过；打包后应用启动、沙箱配置与 SQLite 初始化检查通过。附件提供 SHA-256 校验文件。
