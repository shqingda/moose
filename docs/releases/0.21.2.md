# Moose 0.21.2

桌面与独立 Web 版联合更新，版本统一来自 `package.json`。

发布于 **2026-09-30**，标签为 `v0.21.2`，对应提交 `7ae0093`。[正式 Release](https://github.com/shqingda/moose/releases/tag/v0.21.2)已公开，两端安装包使用同一版本。

## 品牌与图标

- macOS 应用与 Dock 图标采用黑底拟物版，保留金色鹿角、象牙白鹿头和黑色眼睛；官网同步使用黑底标识。
- 会话区欢迎画面使用透明背景的拟物 logo，移除原来的绿色底座；侧边栏标识保持不变。
- Web 与官网 favicon 跟随系统主题：浅色主题使用深色驼鹿剪影，深色主题使用浅色剪影，不受应用内主题设置影响。

## 验证与更新

本版联合发布完成以下验收：

- 格式、Lint、类型与构建通过；30 个单元测试文件中的 **179 项测试**、**67 项桌面／Web E2E** 全部通过，未调用真实模型。
- macOS 打包应用严格签名、版本、renderer 沙箱、SQLite、Shell 命令、PTY 与调度验收通过；包内 ICNS 与本次黑底图标的 SHA-256 一致。
- 独立 Web 无系统 Node 的干净安装、localhost 认证、SQLite、PTY、重复启动、更新不停止任务、重装、停止／重启与浏览器打开通过；本地准备阶段另验证校验失败保留旧安装。
- 正式公网安装入口的安装、运行与更新验收通过后，GitHub Release 才公开并设为最新。

专项图标检查验证了隔离桌面／Web 的透明 logo、侧边栏轮廓一致性，以及模拟系统浅色／深色／浅色切换的 favicon。该专项不额外计入 67 项 E2E，也不代表人工切换 macOS 主题或逐一验证所有浏览器。此前真实 CLI 与模型结果保留原日期，见[能力表](../providers/native-capabilities.md#已验证到哪里)。

## 安装文件

| 文件 | 用途 |
| --- | --- |
| `Moose-0.21.2-arm64.dmg` | macOS 桌面安装包 |
| `Moose-0.21.2-web-darwin-arm64.tar.gz` | 独立 Web 安装包 |
| `Moose-0.21.2-SHA256SUMS.txt` | 两端安装包 SHA-256 校验值 |
| `install.sh` | 独立 Web 安装入口；[公网地址](https://moose.shqingda.workers.dev/install.sh) |

桌面适用于 macOS Apple Silicon，使用 ad-hoc 签名，未进行 Apple 公证。Web 用户执行 `moose update` 获取新版；更新不会停止运行中的后台或任务，任务结束后执行 `moose stop && moose` 使用新版后台。

桌面更新使用菜单检查版本并下载替换，具体步骤见[使用指南](../usage.md#更新桌面版)；默认数据目录与 Web 安装版的区别见[Web 说明](../web.md#独立-web-安装)。
