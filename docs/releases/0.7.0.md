# Moose 0.7.0

## 原生子代理

- Codex、Grok 输入框新增“子代理”开关，请求主代理通过 CLI 原生工具分派独立任务、等待并汇总结果。
- Codex 展示结构化委派活动、子任务状态、模型和结果；子线程审批进入现有审批界面，子线程完成不会提前结束主任务。
- Grok 保留 ACP 委派工具活动及 `rawOutput` 结果。
- 委派选择随草稿、消息和队列保存，活动结果可从历史恢复。

## 修复

- 配置保存期间的旧探测结果不再覆盖新配置，等待同批探测的调用会取得最新配置的结果。
- Shell PATH 探测不再继承上次缓存的 PATH，避免已删除的目录在刷新后继续残留。

## 能力边界

- 子代理由底座执行，会使用额外模型额度；不修改用户的 CLI 子代理开关配置。Pi 暂未提供该入口。
- 当前未提供子代理独立会话、单独取消或逐个模型选择。
- `/goal` 使用底座原生能力；Codex 的 Plan 仍是 Moose 的只读规划模式，不等同于原生 Plan 审批流程。详见[原生能力与当前缺口](../providers/native-capabilities.md)。
- 思考摘要仅展示底座实际返回的文本。本次 Codex `gpt-5.6-luna` 探测回答成功，但未返回摘要，不代表所有模型均不支持。

## 安装

提供 macOS Apple Silicon（arm64）DMG 与 SHA-256 校验值。安装包采用 ad-hoc 签名，尚未 Apple 公证；签名完整性验证不等同于公证。

## 验证

- 格式、Lint、类型检查、41 项单元测试及完整 17 项 Electron 测试通过。
- 真实 Codex、Grok CLI 各完成一次原生子代理最小计算任务并汇总结果；没有据此宣称复杂并行写代码已全面验收。
- arm64 DMG 构建完成，应用签名通过 deep／strict 校验；打包应用实际启动确认版本为 0.7.0、renderer sandbox 开启、SQLite 可用。
- 构建保留既有的前端 chunk 大于 500 kB 提示。
