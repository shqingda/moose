# Moose 0.8.1

## 子代理由底座自主决定

- 移除输入框的子代理按钮，不再追加要求委派的提示词。
- Codex、Grok 根据任务和自身配置决定是否使用原生子代理；Moose 默认接收、展示委派活动与结果，并转接受支持的审批。
- 旧草稿里的子代理开关仅为兼容保留，不再影响发送；Moose 不覆盖底座明确禁用子代理的配置。
- 保留 0.8.0 的原生 Plan 审阅／修改／批准执行，以及 Codex 运行中插话。

## 低成本验收

[第一阶段验收说明](../providers/phase-one-testing.md)提供零模型 token 的本地自动化验证，以及两个短回合的可选真实 Plan 验收。小任务未触发委派是正常行为，不代表 Moose 接入失效。

## 安装

提供 macOS Apple Silicon（arm64）DMG 和 SHA-256 校验文件。沿用 ad-hoc 签名，尚未 Apple 公证。

## 验证

52 项单元测试、完整 20 项 Electron 测试通过；格式、Lint、类型检查通过。本次自动化验收不调用真实模型，不消耗模型 token。构建保留既有前端 chunk 超过 500 kB 的提示。

arm64 DMG 构建完成，签名通过 deep／strict 校验；打包应用实际启动确认版本 0.8.1、renderer sandbox 开启、SQLite 可用。
