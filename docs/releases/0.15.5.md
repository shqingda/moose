# Moose 0.15.5

共享终端增加单控制端交接：桌面和 Web 可以同时查看，一个窗口负责输入和尺寸调整。

- 第一个打开终端面板的窗口获得控制权。其他窗口显示“仅查看”，点击“接管终端”即可交接。
- 服务端拒绝其他窗口的输入和尺寸调整。界面输入携带租约标识，旧租约下延迟到达的按键不会在重新接管后执行。
- 关闭面板释放控制权；异常退出或断网使用 15 秒租约兜底，每 5 秒续租。旧面板的延迟清理不能释放新租约。
- 查看端沿用控制端的行列数，较窄窗口允许滚动查看。输出继续推送给所有窗口，控制权交接不终止 Shell。
- 更新 Web 使用说明、开发计划和面试指南。移动端、云端、多用户权限和系统后台服务不在本次交付范围。

验证：158 项单元测试、46 项完整桌面／Web 回归通过；最终租约隔离与查看端调整后，补跑受影响的终端及 Web 流程。测试默认隐藏窗口，使用隔离数据和测试 CLI，不调用真实模型。

提供 macOS Apple Silicon DMG 与 SHA-256 文件，沿用 ad-hoc 签名，未做 Apple 公证。

最终安装包验收通过：窗口保持隐藏，版本 0.15.5、沙箱、SQLite、Shell、终端停靠及日历编辑正常；签名与 DMG 完整性校验通过。12 项终端／Web 流程补跑通过，只读提示布局及终端背景修正后再次通过 Web 接管与重连验收，并检查截图。
