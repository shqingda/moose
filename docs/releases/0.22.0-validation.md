### 同口径体积测量

单位均为原始字节；App 是普通文件长度之和，首屏是静态 JS 依赖图，gzip 按资源分别计算。基线为 0.21.4，当前为 0.22.0 干净构建。

| 指标 | 0.21.4 | 0.22.0 |
| --- | ---: | ---: |
| 前端资源合计 | 13,719,885 | 11,429,068 |
| 首屏 JS | 728,748 | 730,785 |
| 首屏 JS gzip | 240,703 | 239,889 |
| 按需 JS | 11,904,223 | 9,613,544 |
| 按需 JS gzip | 2,333,636 | 1,807,191 |
| App 文件合计 | 271,261,860 | 268,974,680 |
| DMG | 122,761,520 | 122,318,587 |
| Web 安装归档 | 44,022,950 | 43,499,833 |

前端资源净减少约 16.7%。新增界面与能力使首屏原始 JS 增加 2,037 字节，gzip 减少 814 字节；没有以删除语言或现有功能换取下降。主要优化来自未使用主题与 WASM 入口。净差值包含新增能力成本，未做逐模块因果归因。

打包应用、共享后台、空工作区、隐藏窗口、热缓存且每次重启后台的三次测量：基线就绪 1268／1332／1228 ms，当前 625／609／658 ms；基线合计 RSS 634／523／452 MiB，当前 571／563／564 MiB；当前界面 JS 堆 6.2／5.3／5.2 MiB。少量样本且有其他测试负载，不能视为冷启动保证，也不能声称内存下降。
