# Moose 0.17.0

更新日夜主题，并整理使用、架构与面试文档。

- 日间采用白色工作区、浅灰侧栏和深蓝强调色；夜间采用炭黑面板与柔和黄绿色，参考 [Running Page](https://yihong.run/tracks) 的视觉层次。
- 统一输入框、模型菜单、设置、代码块和浮层的颜色与边框；终端背景、文字和光标跟随界面主题。
- 保留现有布局、快捷键和操作流程，没有新增依赖。
- 合并六阶段验收记录与重复的面试专题，明确当前能力和历史记录，修正后台生命周期、终端及 Web 的过时说明。

验证：159 项单元测试、47 项桌面／Web 回归通过；焦点样式修正后另复测 2 项键盘与主题流程。格式、lint、类型、构建和本地文档链接检查通过。安装包启动、沙箱、SQLite、Shell、PTY、调度、签名及 DMG 校验通过。测试窗口保持隐藏，不调用真实模型。

发行包为 macOS Apple Silicon DMG，使用 ad-hoc 签名，未进行 Apple 公证。
