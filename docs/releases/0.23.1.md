# Moose 0.23.1

修复终端乱码和复制权限问题，继续优化长会话阅读和键盘操作，保留 0.23.0 的加载与资源传输改进。

- 新终端在缺少 UTF-8 字符环境时补齐字符设置，避免 zsh 把提示符中的 Unicode 符号转成乱码。
- 终端复制统一走宿主接口；桌面使用系统剪贴板，Web 在异步 API 被拒绝时尝试用户触发的原生复制。支持 ⌘C 和 Ctrl+Shift+C，保留 Ctrl+C 中断命令。
- 稳定文件上下文、翻译与消息回调，减少工作区变化引起的无关重绘。
- 流式 Markdown 继续复用代码块和本地图片；保留自动换行与复制反馈，避免每次更新重新读取图片。
- 文件树支持 Tab 进入、方向键浏览、Enter 打开及 Tab 离开，再进入时返回上次位置。
- 搜索结果由输入框集中控制，Tab 可直接到达清空和加载更多，Ctrl／⌘+Home／End 跳转当前结果首尾。

macOS Apple Silicon DMG 与独立 Web 使用同一版本联合发布；验证记录见[本版验收](https://github.com/shqingda/moose/blob/main/docs/releases/0.23.1-validation.md)。
