# Moose 0.9.0

## 原生历史与子代理

- 浏览、预览并导入 Codex／Grok 原生历史；重复导入可识别。
- Codex 显式分叉、手动压缩；子代理面板展示来源、历史、状态，以及底座允许的发送和停止操作。
- 操作结果持久化，断连结果未知时不自动重试。恢复关闭子任务仍需主代理执行。

## Worktree 与并行工作

- 从明确 ref 创建独立分支和空白会话，不同 worktree 可并行执行。
- 文件引用、技能、diff、编辑器和底座会话使用当前会话实际目录。
- 支持保留、安全清理、合并预览、冲突处理及重启状态核对；清理保留分支。
- 合并目标为项目根目录当前分支；有未保存内容、活动任务或未合并提交时阻止清理。

## 验证与安装

71 项单元测试、25 项 Electron 回归通过，最后修改后的相关 4 项 Electron 回归通过；类型、Lint、格式检查通过。自动化使用协议 fixture 和临时真实 Git 仓库，不消耗模型 token。真实 Codex 0.155.1／Grok 1.0.34 已验证只读历史接口，未额外调用模型测试压缩或新委派。

[第二阶段验收](feature-validation-history.md#phase-two)和[第三阶段验收](feature-validation-history.md#phase-three)提供低成本复测命令，包括 Node PATH 修复方法。数据库升级至 schema 5，旧版本不支持降级读取。

提供 macOS Apple Silicon（arm64）DMG 与 SHA-256 校验文件；沿用 ad-hoc 签名，尚未 Apple 公证。构建保留既有前端 chunk 大小提示。

arm64 安装包已通过 deep／strict 签名检查，实际启动确认版本 0.9.0、renderer sandbox 开启、SQLite 可用。
