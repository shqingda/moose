# 0.23.1 交互连续性与键盘优化验收

日期：2026-10-03（Asia/Shanghai）。版本以 `package.json` 为准。

**状态：准备发布，尚未完成联合验收。** 正式发布后补齐发行身份、完整测试结果和公开安装核验。

定向验证已通过：双端文件浏览、Markdown 预览、搜索与连续消息更新，共 8 个场景。首轮搜索检查发现滚动容器多余的 Tab 停留点，已修复；图片计数测试改用独立文件，避免把已有历史消息的图片混入计数。

终端补充验证已通过：真实 zsh 在缺失 locale、C、LC_CTYPE=C、LC_ALL=C 下正确展开中文与 Unicode 提示符；双端在异步剪贴板 API 被拒绝时，实际选中终端文本并复制成功，焦点保留。

## 范围与验证

- 文件上下文、翻译函数、消息编辑和打开文件回调保持稳定，避免快照更新打破消息行的 memo。
- Markdown 的渲染组件类型保持稳定，文本增量不再卸载代码块或本地图片。
- 新增双端连续消息回归：五次更新后代码块 DOM 与换行状态保留，本地图片只读取一次。
- 扩展已有双端场景，覆盖文件树 Tab 进出、方向键和焦点返回，搜索首尾跳转、跳过逐结果 Tab，以及主题变化时保留代码块状态。

不将组件复用等同于整机内存或启动时间的量化下降；上一版的首屏与体积数据见 [0.23.0 验收](0.23.0-validation.md)。此次不增加依赖、不改变数据库或任务生命周期。真实 VoiceOver 听读、长时模型负载和系统休眠不由自动化替代。
