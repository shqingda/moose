# Moose 0.14.0

本版修复终端和 Git 操作相互阻塞的问题，并统一工作区界面与快捷键。

- 多个终端和手动 Shell 命令可并行运行；打开终端后仍可预览、提交代码或创建 PR。目录迁移与代理任务继续保留必要的互斥保护。
- 终端标签显示系统用户与主机名，关闭按钮放在各自标签上，关闭后不再显示历史标签。空面板显示“+ 新建终端”，按钮与会话标签等高。
- 终端标签使用整体悬浮背景，关闭图标只改变颜色。浅色终端采用 GitHub Light Default 配色，深色保留 Catppuccin ANSI 配色，背景与深色工作区一致。
- 终端顶部操作栏在弹窗、底部和右侧保持相同字号与控件尺寸。
- macOS 支持 Control+反引号切换终端、Control+Shift+反引号新建终端；补齐后台命令、定时任务与输入框焦点快捷键，设置中可查看。
- 模型选择弹窗保持固定高度，模型列表内部滚动；切换底座和搜索不再引起高度跳动。
- 归档视图只显示已归档会话，移除项目管理操作。精简欢迎页、输入框和右上角工具菜单。
- Git 提交与 PR 窗口自动加载预览，变更详情默认折叠。当前分支与 PR 目标分支相同时显示清楚的说明，并展开目标分支输入。

提供 macOS Apple Silicon DMG 和 SHA-256 校验文件。沿用 ad-hoc 签名，尚未 Apple 公证。

验证：136 项单元测试通过。完整 45 项 Electron 回归首轮 42 项通过；修正依赖系统主题的测试初始化后，后台与扩展两个文件的 15 项全部通过，覆盖首轮失败的 3 项。格式、lint、类型与构建检查通过。测试使用隔离数据和测试代理，未调用真实模型或发布真实 PR。

发行包验收通过：DMG 完整性、deep／strict 签名检查；实际启动 0.14.0 确认沙箱开启、SQLite 可用、Shell 输入输出正常、终端在弹窗／底部／右侧切换后保持同一进程，以及暂停的日历任务可编辑。
