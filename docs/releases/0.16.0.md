# Moose 0.16.0

安装版自动启动本机共享后台，桌面与浏览器可以直接使用同一个工作区。

- 打开应用时按需启动后台，再次打开复用已有服务；继续使用原来的桌面数据库和附件目录，无需迁移数据。
- Moose 菜单增加“在浏览器中打开”，不用从终端复制访问链接。
- 普通退出保留后台任务和终端；“退出并停止后台”结束服务。菜单明确区分这两种行为。
- 升级遇到旧版后台时阻止业务请求，提示先停止旧后台再重新打开；独立模式拒绝打开共享服务占用的数据目录。
- 桌面断开时释放登录会话，浏览器重复打开复用已有登录，避免日常使用耗尽会话名额。
- 更新使用说明、架构、开发计划及面试指南。

本轮不安装系统守护服务，不合并原有独立 Web 工作区。电脑重启不会恢复原来的活进程。源码开发与隔离测试默认仍使用独立后台，可通过 MOOSE_RUNTIME_MODE=shared 验证新入口。

安装包继续提供 macOS Apple Silicon DMG，使用 ad-hoc 签名，尚未进行 Apple 公证。

验证：159 项单元测试、47 项完整桌面／Web 回归通过；补充验证重复打开浏览器链接复用登录。安装包在隔离数据目录使用自动共享模式验收，窗口保持隐藏，版本、沙箱、SQLite、Shell、终端停靠、定时任务及服务清理通过；格式、lint、类型、构建、签名和 DMG 完整性检查通过。测试使用本地夹具，不调用真实模型。
