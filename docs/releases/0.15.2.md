# Moose 0.15.2

修复右侧审阅面板展开后，输入框模型选择器被挤到下一行的问题。

- 输入框工具栏保持单行；窄布局收起权限文字，长模型名省略显示，悬浮可查看完整名称。
- 用量指示器改为圆环并移到模型左侧，统一工具栏的对齐和间距。
- 用量窗口支持悬浮展开，移入窗口可继续阅读，移开关闭；保留键盘快捷键。
- 收紧用量窗口的留白、额度进度条和重置时间排版。

提供 macOS Apple Silicon DMG 与 SHA-256 文件，沿用 ad-hoc 签名，未做 Apple 公证。

验证：150 项单元测试、46 项完整桌面／Web E2E 通过；格式、lint、类型与构建检查通过。安装包签名和 DMG 完整性校验通过，实际启动确认 0.15.2、沙箱、SQLite、Shell、终端停靠和日历编辑正常。未调用真实模型。
