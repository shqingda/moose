# Moose 0.23.3

记住上次的选择，统一各底座的任务模式与权限，并处理好会员过期和 CLI 卡住。改动来自 [PR #4](https://github.com/shqingda/moose/pull/4)。

- 底座、模型、推理强度、权限档位和计划／目标模式都会记住；桌面和 Web 打开就直接恢复，不用等探测。记住的选项不可用时，探测结果出来后再换成仍有效的默认值。
- 四个底座都有计划模式、目标模式，以及请求批准、帮我批准、完全访问三档权限。CLI 有原生接口就直接用，没有就由 Moose 用只读提示、工具拦截或审批代选补齐。新装默认是帮我批准；完全访问只有明确选中才会用。
- Pi 没有可暂停的工具协议：选请求批准时只能中止已经开始的改动；Pi 的完全访问与帮我批准是同一套工具策略。Pi 和 OpenCode 的目标模式不会在回合结束后再自动开下一轮。
- 配置与扩展页一打开就显示上次读到的配置。后台刷新若大约 2.5 秒还没返回，或明确报订阅过期、未登录、模型不可用，只补一行短状态，已显示的配置保持不动。不可用的模型会隐藏，记住的模型失效后再回退。

macOS Apple Silicon DMG 与独立 Web 使用同一版本联合发布；验证记录见[本版验收](https://github.com/shqingda/moose/blob/main/docs/releases/0.23.3-validation.md)。
