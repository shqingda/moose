# Moose 0.11.0

## 配置与扩展管理

- 项目／会话顶部新增配置与扩展入口，显示 Codex 配置来源、有效设置与诊断。
- 支持用户级默认模型、MCP／插件启用开关、插件 CLI 安装卸载及 MCP OAuth；写入前预览、校验配置版本，保存后重新读取核对。
- 支持注册 HTTP／STDIO MCP，提供参数数组和环境变量名引用；新增服务器保存为禁用，再单独启用。
- Hooks 展示事件与来源，命令、环境变量值及凭据不透传到界面；未确认操作不自动重放。

## 后台命令与定时任务

- 顶部终端入口支持 Moose 管理的 Shell 文本命令、输出、标准输入、EOF、停止及退出状态；使用当前会话实际目录，包括 worktree。
- 支持单次／固定间隔的命令或代理消息调度；复用目录锁，错过周期最多合并补跑一次，失败或结果不确定时暂停。
- 定时任务暂停后可编辑名称、类型、正文、下次时间及间隔；预览保存后仍暂停，版本校验防止旧设置覆盖新内容。
- 重启核对已完成命令与持久化队列，避免误判结果或重复入队；运行进程意外退出时清理其拥有的命令进程组。
- 修复原生代码审查取消通知的时序问题，主动停止不再误报失败。

## 支持范围与验证

配置管理首批支持 Codex 0.155+；Grok／Pi 管理适配、项目级配置写入、hooks 编辑及既有 MCP 配置编辑／删除尚未接入。真实配置写入、插件安装和服务端 OAuth 由隔离夹具验证；Codex 0.155.1 已完成真实只读探测。

后台命令为文本管道，暂不支持完整 PTY、全屏程序或底座原生命令接管。定时任务要求应用运行；关闭窗口仍执行，退出应用后不执行，暂不支持日历 cron 或系统唤醒。代理消息可能消耗模型额度。

123 项单元测试、33 项完整 Electron 回归通过；类型、Lint、格式和差异空白检查通过，未调用真实模型。使用说明与零模型 token 复测入口见[配置与扩展验收](feature-validation-history.md#phase-five)和[后台任务验收](feature-validation-history.md#phase-six)。构建保留既有前端 chunk 大小提示。

提供 macOS Apple Silicon（arm64）DMG 与 SHA-256 校验文件；沿用 ad-hoc 签名，尚未 Apple 公证。数据库继续使用 schema 5。

arm64 DMG 已构建并通过映像完整性检查，应用 deep／strict 签名验证通过。实际启动打包应用确认版本 0.11.0、renderer sandbox 开启、SQLite 可用；真实 Shell 标准输入与输出、定时任务创建／暂停／编辑流程通过，全部使用临时数据目录。
