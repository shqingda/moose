# Moose 0.16.2

更新稳定版依赖，并将项目包管理器固定为 pnpm 12.5.1。

- Electron 44.3.0 → 44.4.3，包含 ASAR 文件访问与 require 性能改进；重新构建 SQLite 和 PTY 原生模块。
- Vitest 5.0.1、Zod 4.6.5、Lucide React 1.47.0、Motion 13.4.0、cn 0.3.0。
- Oxlint 1.83.0、Oxfmt 0.68.0；Node 类型维持 22 系列，升级到 22.20.4。
- 同步锁文件与 README，移除旧 Zod 版本已失效的发布年龄例外。

Electron 更新依据：[44.4.3 发布说明](https://github.com/electron/electron/releases/tag/v44.4.3)。

验证：pnpm 12.5.1 冻结锁文件安装通过；159 项单元测试、47 项桌面／Web 回归、格式、lint、类型、构建、安装包验收、签名及 DMG 校验均通过。测试窗口保持隐藏，不调用真实模型。

同口径空工作区三次温缓存启动为 600 / 632 / 649 ms，中位数 632 ms（0.16.1 为 620 ms）；RSS 合计中位数 562 MiB（此前 567 MiB）。没有测出显著启动加速。首屏 JS 仍为 587.98 kB，安装后约 245.1 MiB，DMG 约 110.7 MiB。

发行包为 macOS Apple Silicon DMG，使用 ad-hoc 签名，未进行 Apple 公证。
