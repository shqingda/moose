## 范围

按需加载与欢迎图优化、Web 静态资源流式传输／缓存／gzip、聊天消息增量合并、浮层过渡和按钮可访问性。保留现有数据结构与代理能力，不重启用户活动后台。

## 测量方法

- 构建资源按 `pnpm size:measure` 的静态入口依赖图比较；它不是实际网络瀑布，不能把移动到按需模块的字节记为安装包减少。
- `pnpm perf:web` 使用临时数据库、关闭代理发现、隐藏浏览器窗口，三次导航均禁用浏览器 HTTP 缓存；首轮包含令牌登录，后两轮沿用认证。服务保持温缓存，不清空操作系统磁盘缓存、不模拟慢网，不等同真实公网冷启动。
- `pnpm perf:measure` 使用打包桌面和隔离共享服务，三次隐藏欢迎页热启动；记录进程树 RSS 和 renderer JS 堆。RSS 包含共享页，不能解释为独占物理内存。
- 消息合并微基准使用 10,000 条已加载消息、100 次预热和 2,000 次末行更新，仅衡量合并函数，不能解释为整页帧率提升。

## 最终验证

- `pnpm release:prepare` 与 `pnpm release:publish` 均在发行提交通过；格式、Lint、类型、生产与官网构建、34 文件／207 项单元、79 项桌面／Web E2E 全部通过。
- macOS 严格签名、版本、沙箱、SQLite、命令、终端三种停靠与调度检查通过；独立 Web 干净安装、localhost 认证、PTY、重复启动、更新保任务、重装、校验拒绝、停止／重启与打开浏览器通过。
- 正式 Web 安装器完成真实下载、校验、安装及启动验证；公网清单与本地产物一致，GitHub 四个附件的大小与 SHA-256 匹配，旧 0.22.1 三个下载分片仍返回 200。见[独立发布核验](evidence/0.23.0/publication-result.json)。
- 搜索焦点、清空、选中高亮、关闭中重开与减少动态效果由两端回归覆盖；另目视检查[搜索](evidence/0.23.0/search-preview.png)及[深色欢迎页](evidence/0.23.0/welcome-dark.png)。

首轮完整 E2E 为 74 通过、5 失败：恢复审阅面板在项目选择后准备，布局测量避开浮层进入时的缩放，菜单检查改为实际内容不溢出。相关 5 项定向复测通过，随后完整 79 项通过。打包性能检查又发现根入口 Suspense 引入约 0.5 秒等待，因此改为先解析宿主模块再挂载 React；启动修正后的完整回归暴露虚拟化滚动与窄屏测量的两处时序问题；改为真实滚轮输入及等待布局稳定，连续两轮共 6 项定向检查通过，最终再次完整执行准备流程。保留[被否决候选的性能记录](evidence/0.23.0/perf-suspense-regression.json)。没有绕过发布门槛。
