# 0.23.0 性能与交互更新验收

日期：2026-10-03（Asia/Shanghai）。版本唯一来源为 `package.json`。

**状态：准备中，尚未发布。** 完成实现与定向检查后，从干净提交执行 `pnpm release:prepare`、`pnpm release:publish`；只有桌面、Web 和公网安装检查全部成功才记录联合发布完成。

## 范围

按需加载与欢迎图优化、Web 静态资源流式传输／缓存／gzip、聊天消息增量合并、浮层过渡和按钮可访问性。保留现有数据结构与代理能力，不重启用户活动后台。

## 测量方法

- 构建资源按 `pnpm size:measure` 的静态入口依赖图比较；它不是实际网络瀑布，不能把移动到按需模块的字节记为安装包减少。
- `pnpm perf:web` 使用临时数据库、关闭代理发现、隐藏浏览器窗口，三次导航均禁用浏览器 HTTP 缓存；首轮包含令牌登录，后两轮沿用认证。服务保持温缓存，不清空操作系统磁盘缓存、不模拟慢网，不等同真实公网冷启动。
- `pnpm perf:measure` 使用打包桌面和隔离共享服务，三次隐藏欢迎页热启动；记录进程树 RSS 和 renderer JS 堆。RSS 包含共享页，不能解释为独占物理内存。
- 消息合并微基准使用 10,000 条已加载消息、100 次预热和 2,000 次末行更新，仅衡量合并函数，不能解释为整页帧率提升。

## 优化前后

基线源码 `f936a70`、桌面包 0.22.1；候选构建 0.23.0。原始数据见[测量上下文](evidence/0.23.0/measurement-context.json)、[构建前](evidence/0.23.0/size-before.json)、[构建后](evidence/0.23.0/size-after.json)、[Web 前](evidence/0.23.0/web-before.json)、[Web 后](evidence/0.23.0/web-after.json)。

| 指标 | 0.22.1 | 0.23.0 | 解读 |
| --- | ---: | ---: | --- |
| 前端全部资源 | 11,424,581 B | 10,553,641 B | 减少 7.6% |
| 静态入口 JS | 730,167 B | 223,611 B | 减少 69.4%；工作区仍会在认证后加载 |
| 欢迎图 PNG | 926,074 B | 59,516 B | 减少 93.6%；保留原母图与三倍显示分辨率 |
| 无浏览器缓存的 Web 欢迎页资源正文 | 1,818,213 B | 366,221 B | 包含实际加载的模块、CSS 与图片，减少 79.9% |
| Web 三轮就绪时间 | 1051 / 839 / 833 ms | 1004 / 817 / 826 ms | localhost 样本接近，不宣称已证明真实冷启动提速 |

欢迎图解码 RGBA 的理论大小从约 6.0 MiB 降为 324 KiB，不能等同进程 RSS 减少。Web 三次导航后的 JS 堆存在 GC 时机差异，未证明整体内存持续下降。消息合并的[微基准](evidence/0.23.0/transcript-performance.json)从 937 ms 降至 4 ms，但仅代表 2,000 次末行合并函数调用，不能外推为整页速度。

## 验证状态

格式、Lint、类型、生产构建通过。新增 11 项静态资源 HTTP 测试和 4 项消息合并测试通过。桌面／Web 搜索、文件预览与撤销流程，以及关闭中重开和减少动态效果共 4 项定向 E2E 通过。完整发布门槛与打包后指标待补。

## 保留的边界

真实系统休眠、系统通知授权与展示、VoiceOver 听读和长时间真实模型负载不由自动化结果替代；历史剩余项目见 [0.22.0 TODO](../TODO-0.22.0.md)。本版不修改这些系统集成，不把本次功能回归追认为历史异常关闭根因已修复。应用继续采用 ad-hoc 签名，未增加 Apple 公证。
