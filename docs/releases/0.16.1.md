# Moose 0.16.1

精简低频面板加载和终端恢复逻辑，缩小 macOS 安装包。

- 历史与 worktree 共用弹窗外壳，内容按需加载；计划面板和 Git 审阅按使用阶段加载，保留焦点、关闭动画和原有状态行为。
- 终端恢复在 SQLite 内更新状态，避免将全部历史输出反序列化到 JS；已完成记录保持不变。
- Electron 只分发英语、简体中文及对应资源变体，保留 Unicode 数据与运行组件。
- 修正性能脚本：隐藏运行，并统计桌面及共享服务进程树；更新测试、架构和面试指南。

与 0.16.0 同环境比较：首屏 JS（含预加载依赖）897.30 → 587.98 kB；安装后 291.7 → 244.5 MiB；DMG 122.0 → 110.4 MiB。三次空工作区温缓存启动中位数 627 → 620 ms，RSS 中位数 573 → 567 MiB：没有证明显著启动加速，不夸大内存差异。详细口径和终端历史合成实验见[项目追问资料](../interview/project-interview-reference.md#electron-启动慢包体积大内存高你怎么优化)。

复核后保留 159 项单元测试、47 项 E2E，不删除覆盖不同异常路径的用例；扩展已有终端恢复断言。全量测试、格式、lint、类型、构建、安装包验收、签名及 DMG 完整性检查通过。所有自动化窗口保持隐藏，测试不调用真实模型。

发行包为 macOS Apple Silicon DMG，继续使用 ad-hoc 签名，未进行 Apple 公证。
