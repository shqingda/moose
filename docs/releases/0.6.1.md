# Moose 0.6.1

## 修复与精简

- 修复 Finder 启动后找不到 pnpm 全局安装的 Pi：读取用户登录交互 shell 的 PATH，并将其用于 CLI 发现和子进程启动。
- 查询共用 30 秒缓存，限制输出并设置 3 秒超时；shell 失败时使用原环境及常见目录兜底，覆盖 pnpm、Bun、Volta、Homebrew 等安装位置。
- 服务商未找到 CLI 时显示“未在 PATH 中检测到 xxx”，移除“需要处理”。
- 删除展开区域重复的模型数量和“保存并重新连接”按钮。路径输入失焦自动保存并检测，回车同样生效，不弹成功提示。

## 使用说明

自定义安装位置只要加入 shell PATH，通常无需手工配置 Moose。仅在终端定义的 alias / function 不是可执行文件；没有加入 PATH 的任意目录仍需填写绝对路径。

当前安装包使用经过完整性校验的 ad-hoc 签名，尚未 Apple 公证。下载后 Gatekeeper 仍可能要求在“隐私与安全性”中允许打开。

## 验证

- 35 项单元测试、完整复跑的 15 项 Electron 测试通过，格式、Lint、类型检查及构建通过。
- 模拟 Finder 的精简环境，成功发现并读取 pnpm 安装的 Pi 0.85.1 版本。
- arm64 安装包签名严格校验通过；实际启动确认 0.6.1、sandbox 开启、SQLite 可用。
