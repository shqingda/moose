# Moose 0.22.1

0.22.0 的维护更新：精简设置导航文字与快捷键标题，清理未使用的界面组件和模块导出，保留现有工作区、会话与代理能力。

- 补强合并冲突在桌面重开后的恢复、暂存、完成与中止回归，检查未解决冲突和未暂存改动对提交的限制。
- 补强桌面／Web 连续切换文件与审阅面板、减少动态效果、焦点返回和草稿保留检查；补齐队列编辑、移除、刷新后保留与继续的界面回归。
- 改进长运行诊断的时间戳、关闭／崩溃事件和测试进程清理，归档历史失败及本轮自动验收证据。

桌面 DMG 与独立 Web 同步更新，版本统一为 0.22.1。发布流程完整执行单元、77 项桌面／Web E2E、桌面安装包和独立 Web 安装检查，公网安装验证通过后才公开 Release。已有数据库格式保持兼容；更新不主动重启正在执行任务的用户后台。

真实休眠／唤醒、系统通知展示与点击、VoiceOver 和前台动效人工验收按用户安排另约。历史窗口异常关闭的根因仍未确认；此前源码构建的两小时运行已通过，但不将其追认为本版安装包重新完成了两小时测试。详见[本版验收](https://github.com/shqingda/moose/blob/main/docs/releases/0.22.1-validation.md)及[原始证据索引](https://github.com/shqingda/moose/blob/v0.22.1/docs/releases/0.22.0-evidence.md)。
