# Moose 0.22.0

统一工作区的视觉与交互，保留全部已有功能：侧栏固定新建、搜索、归档与设置；空白会话集中输入，发送后延续到底部；顶部显示实际工作目录，文件、审阅、终端与更多入口保持清晰。中英文、浅深主题、字号与系统辅助功能偏好继续支持。

- 文件与审阅共用面板宽度、键盘调整和焦点返回；面板与侧栏使用可中途反向的无回弹弹簧。终端、命令、定时任务和三种位置继续保留。
- Pi 增加只读 JSONL 历史、去重导入、续聊与经验证的原生插话；OpenCode v2 增加 ACP 历史列表及加载回放。Grok Plan 的协议门槛未通过，继续不开放。
- 提取草稿、布局、代理发现／额度与执行／落库职责；发送回执等待期间的新输入得到保留，后台关闭等待尚未完成的目录准备。
- 删除未使用样式，统一语义变量；收窄未用的高亮主题与 WASM 入口，保留原有语言、离线高亮、SQLite、PTY、通知和签名能力。

功能对照、真实 CLI 版本、体积与启动数据、长运行和人工验收状态见[完整验收记录](0.22.0-validation.md)。已有数据库格式、附件与原生会话标识保持兼容。

桌面 DMG 与独立 Web 使用 `package.json` 中的同一版本，按 `release:prepare`、`release:publish` 联合发布。更新时保留原数据和活动任务；若后台版本不同，等待任务结束后再重启后台。仍采用 ad-hoc 签名，未新增 Apple 公证或其他平台安装包。
