# Moose 0.21.3

2026-09-30，macOS 桌面与独立 Web 版联合更新，版本统一来自 `package.json`，标签为 `v0.21.3`。[GitHub Release](https://github.com/shqingda/moose/releases/tag/v0.21.3)。

## 界面与图标

- macOS 应用和 Dock 改用白底拟物图标，保留金色鹿角、象牙白鹿头与黑色眼睛。官网保留黑底标识，欢迎页继续使用透明 logo。
- 欢迎页的蓝色“打开项目”按钮改为中性色文件夹入口，展示操作名称和选择文件夹提示。
- 顶部侧栏、菜单、终端、文件与审阅图标统一为 17×17、相同线宽和灰色；图标按钮的悬停、展开和选中反馈统一。

## 终端面板

- 打开终端面板时，没有标签则自动创建首个标签；已有标签则复用现有 Shell。按钮与快捷键共用初始化逻辑，避免重复创建。
- 关闭最后一个标签，或最后一个 Shell 自行退出时，整个面板自动收起；底部、右侧和弹窗行为一致。
- 关闭单个标签仍先确认结束 Shell，默认聚焦取消；只收起面板不停止终端进程。切换停靠位置保留标签、Shell 与输出。

## 发布验证与更新

联合发布使用 `pnpm release:prepare`、`pnpm release:publish`。准备阶段覆盖格式、Lint、类型／构建、全部单元与桌面／Web E2E、桌面严格签名与包内运行、独立 Web 干净安装与更新保留任务；部署后从正式公网入口重新安装并验证，通过后才公开 GitHub Release。

验证使用隔离数据，不迁移或删除现有工作区，也不向真实模型发送任务。底座协议和此前真实 CLI 的验收日期保持原记录。

| 文件 | 用途 |
| --- | --- |
| `Moose-0.21.3-arm64.dmg` | macOS Apple Silicon 桌面安装包 |
| `Moose-0.21.3-web-darwin-arm64.tar.gz` | 独立 Web 安装包 |
| `Moose-0.21.3-SHA256SUMS.txt` | 两端安装包 SHA-256 |
| `install.sh` | [独立 Web 公网安装入口](https://moose.shqingda.workers.dev/install.sh) |

桌面用户下载新版并替换应用；普通退出保留共享后台。若提示后台版本不同，等活动任务结束后停止旧后台，再打开新版，见[桌面更新](../usage.md#更新桌面版)。独立 Web 用户执行 `moose update`；运行任务保留，任务结束后执行 `moose stop && moose` 使用新版，见[Web 更新](../web.md#更新独立-web-版)。
