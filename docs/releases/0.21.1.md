# Moose 0.21.1

桌面与独立 Web 版联合更新，继续使用同一个 `package.json` 版本。

## 界面与文件查看

- 侧栏用状态图标表达运行、等待、排队及异常，完成时不显示对勾；移除重复的工作文字和终端空面板说明。
- 代码块使用一体式卡片、语言标题、图标复制与换行控制；设置导航缩短为 Extensions / 扩展。
- 图片附件使用整张缩略图预览，文件标签、终端标签及侧栏行统一整块悬浮反馈。
- 本地文件在右侧面板打开：文件树、多标签、面包屑、查找、复制、下载、缩放与展开／还原，保留聊天草稿。
- 源码采用本地打包的 Pierre / Shiki 只读预览；Markdown 默认渲染，支持源码切换及文件相对链接。暂不提供编辑保存或语法折叠。

## 引导、恢复和通知

- 缺少 CLI 时复制安装命令，已有 CLI 时复制登录命令；操作由用户在终端完成。
- 认证失败可直接进入代理设置，未知写入提供“核对状态”，不重发操作；消息加载、复制、审批等界面保留结构化错误。
- macOS 通过应用自身的原生权限桥接读取通知授权状态，仅主动开启通知时申请授权，拒绝不会误开启。返回应用时重新读取状态。
- 共享后台协调桌面与 Web 通知，前台对应会话不提醒，通知点击恢复会话。

## Web 更新

独立安装版新增 `moose update`。下载与校验失败保留当前版本，更新文件不会停止正在运行的后台或任务；任务结束后执行 `moose stop && moose` 使用新版后台。0.21.0 及更早版本需要先重新执行一次安装脚本，以获得此命令。

## 验收边界

联合发布流程执行全套自动检查，验收桌面包（含真实系统权限状态读取）、独立 Web 干净安装、更新不停止任务及公网安装入口。新回归覆盖混合客户端通知去重／点击定位／前台抑制、保存失败保留输入、归档撤销暂停计时、历史查阅期间流式更新及未知写入不重发。

系统授权弹窗的人工点击、通知中心实际展示及 VoiceOver 听读未以模拟测试冒充人工验收。桌面仍为 macOS arm64、ad-hoc 签名，未进行 Apple 公证。
