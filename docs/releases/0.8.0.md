# Moose 0.8.0

## 原生计划

- Codex `/plan` 接入底座原生 Plan 协作模式，规划期间保持只读权限。
- 计划以独立卡片展示，可审阅、修改并保存版本；批准绑定具体版本，防止过期或重复执行。
- 批准后在同一会话切回执行模式，恢复该会话的权限设置；规划完成后暂停后续队列。
- 计划正文、版本和批准记录持久化，刷新后可继续审阅。

## 运行中插话

- Codex 运行时新增“立即发送”，通过原生 `turn/steer` 向当前回合追加输入；普通发送继续进入队列。
- 支持引用、技能和附件，保留当前回合的模型与权限；任务模式变更需排队。
- 显示已接收、明确拒绝或结果未知。拒绝时保留输入，超时和断连不自动重发；同一投递 ID 不重复执行。
- 修复 `turn/start` 响应先于启动通知时不能立即插话的时序问题。

## 支持范围

本次原生 Plan 与插话仅支持 Codex；实测版本为 Codex 0.155.0、`gpt-5.6-luna`。Grok ACP 当前未提供已验证的 Plan 模式入口，Grok 与 Pi 保留原有发送行为。子代理独立面板、Worktree 等后续功能仍在实施计划中。

## 安装与验证

提供 macOS Apple Silicon（arm64）DMG 和 SHA-256 校验文件。沿用 ad-hoc 签名，尚未 Apple 公证。

真实 Codex 在隔离目录验证了原生计划不改文件、按修改后的计划执行、同回合插话。发布检查结果见[测试与验证](../testing.md)。构建保留既有前端 chunk 超过 500 kB 的提示。

发布前完整复跑 52 项单元测试和 20 项 Electron 测试，均通过；格式、Lint、类型检查通过。

arm64 DMG 构建完成，应用签名通过 deep／strict 校验；打包应用实际启动确认版本为 0.8.0、renderer sandbox 开启、SQLite 可用。
