# Moose 0.15.4

终端输出改为事件推送，浏览器断线后按游标补偿；日常回归默认在后台运行。

- 移除终端内容每 100 ms 的轮询。桌面使用 IPC，Web 与共享桌面复用 SSE；服务端每 33 ms 合并新增输出。
- 首次打开、重连及输出缺口按游标补读。实时推送与补读重叠时去重；渲染繁忙时合并为一次补读，避免客户端排队保存大量输出。
- 保留有上限的回放缓冲和明确的截断提示。输入仍走请求接口，断线不自动重发；多客户端输入与尺寸控制权仍待实现。
- E2E 和安装包验收默认隐藏窗口与 Dock 图标，保留截图、trace 和真实 IPC／PTY 流程。需要前台验收时设置 `MOOSE_TEST_BACKGROUND=0`；正常运行应用不受影响。

验证：154 项单元测试、46 项完整桌面／Web 回归通过；补充浏览器断网复测，确认离线输出恢复一次、空闲时无终端内容读取请求。格式、lint、类型与构建检查通过。测试均使用隔离数据和测试 CLI，未调用真实模型。

提供 macOS Apple Silicon DMG 与 SHA-256 文件，沿用 ad-hoc 签名，未做 Apple 公证。

安装包验收通过：窗口保持隐藏，版本 0.15.4、沙箱、SQLite、Shell、终端停靠和日历编辑正常；严格签名及 DMG 完整性校验通过。
