# Moose 0.19.2（重新发布）

以 0.19.1 的细边框图标为基础，恢复更明显的左上高光、右下反光与拟物材质。保留完整图标边缘与透明留白。

此版本替换此前发布的 0.19.2 粗边框安装包；已下载旧包的用户需重新下载安装。本次无功能或数据格式变更，0.19.1 安装包仍保留。

发行包为 macOS Apple Silicon DMG，使用 ad-hoc 签名，未进行 Apple 公证。

验证：格式、Lint、类型与构建检查通过；166 项单元测试和 48 项桌面／Web 回归通过。安装包版本、后台启动、沙箱、SQLite、Shell、PTY、调度与严格签名验收通过。macOS 27 系统图标接口验证未出现白色底板，并与 0.19.1 的系统显示外轮廓对照检查。
