# Moose 0.20.1

桌面版与 Web 独立安装版同步发布，统一版本号 0.20.1。

## 界面稳定性

- 桌面窗口现在等待 Electron 首帧与 React 工作区快照都准备完成后再显示，首次启动和再次启动不再短暂显示加载页或错误主题。
- 主题、字体缩放、减少动态效果、减少透明度和高对比度设置在工作区首帧绘制前应用，避免亮暗主题切换闪烁。
- 侧边栏折叠改为单一、临界阻尼且可中断的宽度动画；可见过渡完成后才把侧栏停放到视口外，避免宽度与位移动画不同步造成的闪屏。
- 保留系统“减少动态效果”设置；桌面与 Web 的侧栏终态、键盘入口和无障碍状态保持不变。

## 发布验证

发布流程执行格式、Lint、类型与构建检查，170 项单元测试和 50 项桌面／Web 回归；启动回归刻意延迟工作区快照，分别验证首次和再次启动只显示完整深色工作区。随后验证 macOS arm64 桌面签名、沙箱、SQLite、Shell、PTY 和调度，以及无系统 Node 的 Web 干净安装、重装、启动和公开安装地址。自动回归使用隔离数据与本地夹具，不调用真实模型。

桌面 DMG 与 Web 安装包均针对 macOS Apple Silicon。桌面使用 ad-hoc 签名，未进行 Apple 公证。
